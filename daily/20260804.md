## 学び: 肩の鍛え方

「ショルダープレス (マシン) だけでいいか、サイドレイズも要るか」の相談から。

### 結論: サイドレイズは要る。優先度も高い

三角筋は 3 束に分かれていて、担当する動作が違う。

```
三角筋 3 束
 ├ 前部 -> ショルダープレス + チェストプレス で過剰気味
 ├ 中部 -> サイドレイズでしか入らない  <- ここが空白
 └ 後部 -> ラットプル / ロウ系 で足りてる
```

プレス系は肩を「前に押す」動作なので、主に前部 + 三頭が働く。中部 (肩幅を作る部分) は **腕を横に上げる外転動作** でないとほぼ入らない。

現状はチェストプレス 110 kg 級をやっているので前部はむしろ過剰。Pull もしっかり入っているので後部も足りている。**中部だけが完全に空白**。

なお memory の `fitness-gym.md` に 6/4 時点で「Push のサイドレイズ (中部) / リアデルト (後部) が抜けがち -> 家で拾うと肩が完成」と書いてあり、そこから 2 ヶ月放置されていた。

### サイドレイズのやり方

- ダンベルを体の横に持ち、**肘を軽く曲げたまま**腕を真横に上げる。
- **肩の高さ (地面と平行) で止める**。それ以上上げると僧帽筋の担当になって中部から外れる。
- 下ろすのはゆっくり。ここで効かせる。
- 重量は **5 ~ 8 kg で 12 ~ 20 回**。中部は小さい筋肉なので軽重量高レップが効く。24 kg は使わない。

**一番多い失敗は「重すぎて体を振る」**。反動を使うと負荷が僧帽筋 (首の後ろ) に逃げて、狙った中部にほぼ入らない。「軽すぎない?」くらいがちょうどいい。

最初の 1 回は桜街道店の **ラテラルレイズマシン**で感覚を掴むのもあり。軌道が固定されているので反動を使いようがない。
