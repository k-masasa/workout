### 体重 -5.5 kg の内訳

```
体重 -5.5 kg
 ├ 脂肪      -3.0 kg   (55%)
 ├ 骨格筋    -1.1 kg   (20%)
 └ その他    -1.4 kg   (25%)  <- 水分 / 内臓 / 骨など
```

BIA の「骨格筋量」は除脂肪組織の一部でしかなく、除脂肪には体水分・内臓・骨・平滑筋も含まれる。減量するとグリコーゲンの結合水や細胞外液も減るので、その他の 1.4 kg はほぼそこ。

**減量分の 55% が脂肪、骨格筋の損失は 20%**。減量に伴う除脂肪の損失は通常 20 ~ 30% (何もしなければ 30 ~ 40%) なので、標準range の良い側に収まっている。

## 学び: BIA の数値の読み方

### 骨格筋量は単調減少していない

```
4/10  27.3 kg
5/25  26.7 kg  (-0.6)
8/4   27.1 kg  (+0.4)   <- 戻っている
8/17  26.2 kg  (-0.9)
```

減り続けているなら本物の筋肉減だが、上下に振動しているのは **BIA の測定誤差の典型パターン**。振れ幅は 26.2 ~ 27.3 kg の約 1.1 kg。

### なぜ振れるのか

```
BIA の推定経路
 電気抵抗 -> 体水分量 -> 除脂肪量 -> 骨格筋量  (推定の 3 段重ね)
```

除脂肪組織が水分を多く含み電気を通しやすい性質を使っているので、**体水分が動くと推定が全部ズレる**。

- グリコーゲンが枯渇すると結合水も抜ける (グリコーゲン 1g につき水 3g を保持)。
- 激しいトレの後は炎症で細胞外に水が移動し、細胞内外の水分比が変わる。

**8/17 の計測は 8/16 の足デー (レッグプレス 135×10×3 ほか) の翌朝**。低く出る条件が揃っている。

### 訂正: 筋力向上は筋肥大の証拠にならない

会話の中で「筋力が上がっているのに筋肉が減ることは基本ない」と言ったが、**これは言い過ぎだった**。筋力向上には 3 つの要因がある。

- **神経系の適応** (運動単位の動員率、発火頻度、拮抗筋の抑制解除)
- **フォームの習熟** (同じ筋量でも技術が上がれば挙がる)
- **筋肥大**

筋量が減りながら筋力が上がることは普通に起こる (階級競技の選手が減量しながら筋力を維持するのがこれ)。**ジム入会が 5/24 でまだ 3 ヶ月、マシン種目はどれも 5 月が初めて**なので、今はむしろ神経系の伸びが最も大きい時期。ここの筋力向上を筋肥大の証拠には使えない。
