これまで README / memory では「レッグプレス 165 kg への急な更新 (5/29 の 145 kg から 1 週間で +20 kg) が原因」とだけ記録していたが、**フォーム要因と追い打ち要因が加わった**。

### 裏付け

- **膝を完全伸展でロックすると、荷重が大腿四頭筋から膝蓋大腿関節に直接乗り換える**。165 kg でこれをやれば関節側に入る。レッグプレスで最も典型的な膝の壊し方。
- **関節由来の痛みは筋肉痛と違って発生が遅れて長引く**。DOMS のピークは 24 ~ 48 時間なので、6/5 の 4 日後 (6/9) に出てくるのは筋肉ではなく関節のタイムラインと整合する。
- **6/6 の 7,000 m / 90 分が追い打ち**。当時の `daily/20260611.md` にも「前回 (6/6 屋外 7km) で逆に膝に来た前科がある」と自分で書いていた。**関節に負荷を入れた翌日に 90 分歩いている**。

### 当時の自分も 165 kg を疑っていた

`daily/20260611.md` の TODO にこう残っている。

> 次の Legs 日: レッグプレス **165kg は更新せず 155kg 前後**でコントロール重視を 2 ~ 3 週キープ

原因の特定は当時から合っていて、**今回足りていたのは「なぜ 165 kg が悪かったのか」の中身**だった。重量そのものではなくロックアウトの問題なら、対策は「重量を抑える」ではなく「伸ばし切らない」になる。

## 今後の運用

1. **レッグプレスで膝をロックアウトさせない**。伸ばし切る手前で止めて、大腿四頭筋のテンションを抜かない。
2. **高重量の脚デーの翌日に長時間の有酸素を入れない**。6/5 -> 6/6 の並びを繰り返さない。
3. 重量の更新幅は引き続き抑える (145 -> 165 の +20 kg 幅は速すぎた)。

9/3 に 145×10 まで戻ってきているので、**次に 155 kg を試す時がこの 3 つを守れるかの本番**になる。
