## やってること

固定スケジュールは決めてない。ベースは Push / Pull / Legs 系で回しつつ、その日の体調 / 天気 / 家族の体調に合わせて柔軟に組み替える。

- **ジム行ける日はガッツリ** (エニタイムフィットネス桜街道店、2026-05-24 入会)
- **自宅でも回せる** (ダンベル最大 24 kg + 懸垂バー)。天気悪い日 / 軽め日は自宅
- **休める時は休む**。連戦で疲れ溜まったら有酸素 / アクティブレストに切替
- 食事はタンパク質を1日体重 × 2.0 g は確保
