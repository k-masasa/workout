## トレーニング方針

```
分割: PPL × 2 周回 (週 6)
   月 Push / 火 Pull / 水 Legs / 木 自宅懸垂 / 金 Push / 土 Pull / 日 Legs

目標: リコンプ (筋肉維持 ~ 微増 + 脂肪減)
   3 ヶ月後  -> 体重 78 ~ 80 kg / BF 22 ~ 23 % / 骨格筋 27 ~ 28 kg
   6 ヶ月後  -> 体重 75 ~ 77 kg / BF 18 ~ 20 % / 骨格筋 28 ~ 29 kg

食事: TDEE -200 ~ 300 kcal (= 2,500 ~ 2,900 kcal/日)
   タンパク質: 体重 × 1.6 ~ 2.0 g/日 = 130 ~ 170 g/日
```

ジム: エニタイムフィットネス桜街道店 (2026-05-24 入会)。自宅はダンベル最大 24 kg + 懸垂バー。
